# Support

This milestone does not promise production self-host support.

Supported for public validation:

- Running no-secret examples.
- Calling approved tools through REST and MCP.
- Inspecting safety tests and contracts.
- Reporting bugs against runtime safety behavior.

Not supported yet:

- Production HA deployments.
- Connector marketplace support.
- Hosted SaaS account operations.
- CIS connector publication.
