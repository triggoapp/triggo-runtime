# Licensing

Current runtime package metadata is `UNLICENSED`.

Allowed language today:

- Public artifact.
- Public contracts and examples.
- Runtime safety nucleus.

Do not use:

- Open source runtime.
- OSS runtime.
- Open-core runtime source.

If the runtime source later uses FSL, call it source-available or fair-source. Use open source only for OSI-approved licenses such as Apache 2.0 or AGPLv3.
